
🍃 Automated MongoDB Backup & Cloud Sync

An automated database backup and retention solution designed to create consistent snapshots of MongoDB databases using mongodump, compress them into timestamped archives, and upload them securely to remote/cloud storage (such as AWS S3 or secondary backup drives) via automated scheduled tasks.

📌 Features

Automated Dump Generation: Uses MongoDB Database Tools (mongodump) with optional --gzip archive compression.

Timestamped File Versioning: Dynamically names backup files (backup-YYYY-MM-DD_HH-MM-SS.gz) to avoid overwrites.

Retention & Cleanup Policy: Automatically purges local backups older than a defined threshold (e.g., 7 or 30 days) to prevent disk overflow.

Cross-Platform Scheduling: Configured for scheduling via:

Linux: Cron jobs (crontab)

Windows: PowerShell script via Windows Task Scheduler

Fail-Safe Logging: Logs backup status, timestamps, and transfer logs for audit readiness.

⚙️ Prerequisites

MongoDB Database Tools:
Ensure mongodump and mongorestore are installed and added to your system PATH.

Download MongoDB Database Tools

Cloud CLI (Optional / Cloud Sync):

AWS CLI configured via aws configure (if streaming or copying to an S3 bucket).

Execution Permissions:

On Windows: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

On Linux: chmod +x backup.sh

🚀 Quick Start & Usage

1. Manual Backup Test

Run a single-command compressed dump to verify database connectivity:

# Using URI string
mongodump --uri="mongodb://localhost:27017/<DB_NAME>" --archive="backup-test.gz" --gzip


2. Automated Script Execution

On Windows (PowerShell)

.\Demo_Code_File.ps1 -DatabaseName "myDatabase" -BackupPath "C:\Backups\Mongo"


On Linux (Bash)

./backup.sh


⏰ Scheduling Automated Backups

Option A: Windows Task Scheduler (PowerShell)

Open Task Scheduler (taskschd.msc).

Click Create Basic Task → Name it MongoDB-Daily-Backup.

Set Trigger to Daily at your preferred time (e.g., 02:00 AM).

Action: Start a program:

Program/script: powershell.exe

Add arguments: -ExecutionPolicy Bypass -File "C:\path\to\Demo Code File"

Option B: Linux Cron Job

Open the crontab editor:

crontab -e


Add the following line to run the backup daily at 2:00 AM:

0 2 * * * /bin/bash /path/to/backup.sh >> /var/log/mongo_backup.log 2>&1


🔄 Restoration Procedure

To restore a database snapshot generated by this pipeline:

mongorestore --uri="mongodb://localhost:27017" --archive="backup-YYYY-MM-DD_HH-MM-SS.gz" --gzip --drop


⚠️ Note: The --drop flag replaces existing collections with the same name prior to restoration. Omit --drop if appending data.
